# Nixos_Hospital
Utilisation de Nixos dans l'hopital / Nixos use in the hospital

Voici des exemples d'utilisation de Nixos en milieu hospitalier
[Médecins Sans Frontières](https://archive.fosdem.org/2025/events/attachments/fosdem-2025-5165-nixos-doctors-without-borders-msf-why-we-use-it-and-how/slides/237831/Presentat_yoE4oU0.pdf).
[Solution pour bloc opératoire VitVio](https://www.youtube.com/watch?v=e6KidH_yuVU)

Nixos peut être utilsé aussi bien pour les serveurs que pour les postes de travail.
Concernant le poste de travail, l'état français développe un distribution Linux basée sur Nixos appelé [Sécurix](https://github.com/cloud-gouv/securix). Elle pourrait être utilisé dans le milieu hospitalier pour sécuriser les postes de travail, avoir un déploiement à l'identique au niveau du parc de machines et sortir de la dépendance à Windows. Couplé à un portail d'accés multiapplication/multios comme [Apache Guacamole](https://guacamole.apache.org/)
